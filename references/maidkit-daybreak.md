# MaidKit Daybreak Case Study

MaidKit was the first practical case used to test the language on an SSH-oriented tool.

## Product constraints that shaped the language

- Existing Servers, Assets, Projects, Snippets, Agent, and Settings entry points.
- SSH sessions with tabs and split panes.
- Server health and latency information.
- Windows and Android as important targets.
- Terminal content must remain readable.

## Lessons

- A visual redesign must reach every affected page, not just the dashboard.
- Latency must have semantic bands, not a single static color.
- Window controls and shell chrome need to belong to the same hierarchy as the rest of the application.
- Dense operational content should use stronger surfaces than decorative background layers.
