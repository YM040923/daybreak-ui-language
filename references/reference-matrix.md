# Reference Matrix

| Dimension | Daybreak contribution | Target product responsibility |
|---|---|---|
| Visual language | Warm light environment, restrained surfaces, orange emphasis | Keep brand and contrast requirements |
| Information architecture | None by default | Preserve the target product |
| Interaction model | Clear feedback and state transitions | Preserve actual actions and platform conventions |
| State semantics | Normal, loading, empty, offline, error, recovery, latency bands | Map to real data |
| Platform behavior | Desktop workbench, mobile thumb-first | Follow platform navigation and input |
| Content voice | Chinese-first, technical terms only when real | Follow the product's language |
