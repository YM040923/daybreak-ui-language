# Accessibility Rules

- Maintain readable contrast on warm surfaces.
- Do not use color as the only state signal.
- Provide visible keyboard focus.
- Keep interactive targets at least 44 by 44 px where practical.
- Preserve native keyboard navigation on desktop.
- Preserve platform back behavior on mobile.
- Respect reduced-motion settings.
- Provide a solid-surface fallback when transparency or blur is unavailable.
- Do not put dense terminal or code text over a busy background.
- Keep labels available to screen readers even when visual UI is compact.
- Test long Chinese labels, long hostnames, and high text scaling.
