# Daybreak Tokens

Tokens are a baseline, not a license to ignore context. A target product may need to adapt them for contrast, platform, or brand requirements.

## Palette

| Token | Value | Use |
|---|---|---|
| `accent` | `#F48120` | Primary action and active emphasis |
| `accent-pressed` | `#C96616` | Pressed and deep emphasis |
| `daylight-top` | `#FFE8D1` | Warm environment |
| `daylight-middle` | `#FCF2E3` | Warm environment |
| `daylight-bottom` | `#F5F4F0` | Quiet neutral base |
| `ink` | `#2A2018` | Main text |
| `muted` | `#756457` | Supporting text |
| `line` | `#E5CDBB` | Warm boundary |
| `surface` | `rgba(255,255,255,.84)` | High-opacity island |
| `surface-soft` | `rgba(255,248,242,.64)` | Secondary surface |
| `terminal` | `#14120F` | Dense terminal content |
| `success` | `#247A55` | Healthy state |
| `warning` | `#A66A13` | Watch state |
| `danger` | `#B84436` | Failure state |
| `offline` | `#7D746D` | Offline or unknown state |

## Radius

- `island`: 24 px
- `control`: 16 px
- `compact`: 10 px
- `pill`: 999 px

## Spacing

- `1`: 4 px
- `2`: 8 px
- `3`: 12 px
- `4`: 16 px
- `5`: 20 px
- `6`: 24 px
- `8`: 32 px
- `10`: 40 px

## Shadow

Use a warm-tinted, low-opacity shadow:

```text
0 18px 42px rgba(96, 58, 30, .14)
```

Do not use a black shadow as the default light-theme elevation.
