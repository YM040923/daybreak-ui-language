# Screenshots

这些图片是 MaidKit Daybreak Windows 界面的实际运行截图，用来展示设计语言落地后的页面层级、组件密度、状态表达和响应式工作台形态。

| 文件 | 展示内容 |
| --- | --- |
| `dashboard.png` | 服务器仪表盘：服务器卡片、负载/内存/运行时间小组件、延迟状态和主要操作 |
| `activity.png` | 服务器活动页：活动导航、实时指标、图表区域和资源状态 |
| `assets.png` | 资产页：SSH 连接、GitHub 登录空状态和凭据区域 |
| `projects.png` | 项目页：项目空状态、新建项目和 TOML 导入入口 |

## 来源

图片由项目使用者直接从 Windows MaidKit Daybreak 界面截取，并在本仓库中作为视觉参考材料保存。它们不是本仓库 Demo 自动生成的示意图，也不是 MaidKit 源码副本。

截图中的服务器地址、状态数据和账号信息属于截图当时的本地示例环境。将这些图片用于公开仓库前，请确认其中没有不希望公开的环境信息。
