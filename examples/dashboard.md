# Dashboard Pattern

Use a dashboard only when the product genuinely has multiple related operational signals.

Recommended order:

1. Page purpose and primary action.
2. Current context or selected resource.
3. Primary status and freshness.
4. Small metrics with units.
5. Main work surface.
6. Recovery or secondary actions.

Do not fill the page with decorative metric cards. A metric belongs in a compact component only when it supports a decision.
